How to run the monitor

  1. Keep this simulator running (start.bat).
  2. Double-click monitor.bat in the same folder. A console window opens and lists the current alerts.
  3. Change something in the Simulator — e.g. 15 cm rain tomorrow in Bellandur.
  4. Within 1–2 s a new line appears in the console window, in logs/monitor.log, in logs/alerts.jsonl and in the table on this page.

What it watches

EXTREMERed rain / wind / heat · river at or above HFL · dam at or above FRL
HIGHOrange rain · river above danger level · dam ≥ 90% full
WATCHYellow — only when started with --include-yellow
CLEAREDan alert that is no longer active
It reports only changes: NEW, UPGRADED, UPDATED, DOWNGRADED, CLEARED. It is a rule-based watcher; an AI agent would sit on top of its output.
